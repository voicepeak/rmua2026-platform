# G1 P03–P05：无断点重复采集

采集前固定：P03/P04 使用历史 `roll_pitch` 原始波形，再在新的独立进程以 seed 314159 和 27182 各重复一次；P05 使用历史 `yaw` 波形，在新进程以 seed 27182 重复一次，结合已有 seed 2026 和 314159 记录。原脚本的小幅波形、保护、隔离进程、停止和数据留存规则保持不变，不使用运行时 GDB 断点，不依据结果修改波形或阈值。每次记录退出状态、配置、实际发送命令、ROS 位姿与 IMU、异常和保护触发；逐次启动避免端口冲突。

这些是重复性研究，不是保留集，历史记录曾用于探索；不同 seed 不保证风、初态、运行条件相同，运行时碰撞与状态同步需另核实。之后需结合初态差异和实际输入时序分析，不以成功启动或三份记录自动判定 G1 通过。P01、P02、P06 仍需按其波形和频率核对足够重复、保留集和覆盖情况。

在查看比较结果前固定分析：沿用 P02 的第一条 PWM 发布源时间后 0.30–0.80 s、10 ms 网格，平移和旋转分别相对窗口起点归一化，报告每个初态、命令切换时间和两两位置/姿态差异。该窗口只覆盖波形的一部分，不得将其扩展为整个 P03–P05 动作包线的结论。

三次新增采集均显示 player=0、stop=0，专用容器停止；collector 因停止而中断的状态保存在各运行记录中。[对照结果](v2_axis_repeatability.json)中，横滚/俯仰三组两两位置最大差为 5.84、4.01、2.24 mm，相对姿态最大差为 1.094°、0.350°、0.768°；偏航位置最大差为 0.57、1.74、2.31 mm，相对姿态最大差为 0.0046°、0.0002°、0.0047°。横滚/俯仰窗口内单次最大相对姿态变化约 5.19–6.11°，偏航约 0.447–0.451°。这些值是样本间描述性差异，不是模型误差或官方容差；三个不同初态、时间对齐、风和潜在接触对结果的贡献尚未分离。

后续对相同窗口的 IMU 作探索性检查：[初始角速度诊断](v2_axis_initial_rates.json)显示横滚/俯仰三组起点角速度差范数约 0.0083、0.0186、0.0114 rad/s，窗口内角速度差 RMSE 约 0.0412、0.0161、0.0334 rad/s。IMU 噪声、延迟、参考时钟和碰撞尚未验证；初速度差按恒定角速度估计的角度仅为量级参考，不能直接作为姿态误差的归因或修正。
