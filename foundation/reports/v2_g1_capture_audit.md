# G1 官方 PWM 采集清点

本清点由 [audit_v2_measurements.py](../audit_v2_measurements.py) 生成，原始清单、每次的波形、文件哈希和排除原因在 [v2_g1_capture_inventory.json](v2_g1_capture_inventory.json)。只纳入指定普通采集模式，检查进程及 player 正常结束、基准二进制和配置哈希、采集脚本哈希、实际 PWM 阶段序列与声明一致，以及位姿、IMU、PWM 回显均有记录。旧版共模播放器将四个相同 PWM 记为单个标量，清点时仅将其展开为四个同值再比较。

| V2 实验 | 现有可清点的主波形记录 | 仍缺什么 |
| --- | --- | --- |
| P01 共模稳定段 | `cadence50` 三次同波形记录；另有两次同阶段共模记录 | 稳定段是否无接触、真实初态和实际施加时间；独立保留波形与误差预算 |
| P02 共模阶跃 | `small_steps` 三次同波形记录 | 不同幅度和初态覆盖、无接触及独立保留评价 |
| P03/P04 横滚/俯仰 | `roll_pitch` 组合波形三次；较小幅度另有一次 | 小幅波形重复与完整包线、时钟及无接触确认 |
| P05 偏航 | `yaw` 三次同波形；较小幅度另有一次 | 小幅波形重复与完整包线、时钟及无接触确认 |
| P06 命令频率 | 20、50、100 Hz 各三次同阶段记录 | 不同频率下实际控制生效时刻、初态和接触影响 |

“可清点”仅表示记录和元数据通过上述检查。控制脚本记录表明这些模式未配置 GDB，但并非对每个历史进程的独立运行栈证明；首末时间和样本数量不证明每个评测窗口都满足采样质量。相同声明和已发送的 PWM 也不证明物理系统收到的实际动作一致。自然风、碰撞、初速度与参考时钟仍未充分控制，且已有记录曾用于探索或拟合。三个 V2 独立保留集已封存，未纳入此清点的模型拟合；正式阈值仍未冻结。

第二轮参数校准未达到预先设定的工程筛选条件，按 V2 停止继续扩展该参数实验。上表列出缺口并不自动启动更多 G1 参数搜索；须先解决 [第二轮报告](v2_calibration_round2_protocol.md) 中的可辨识测量问题。G1 保持 PARTIAL。
