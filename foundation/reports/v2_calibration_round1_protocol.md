# G1 第一轮有限校准：电机响应和命令延迟

## 预先声明

假设：目前候选模型中的电机时间常数与命令生效时刻不准确，造成横滚/俯仰与偏航角速度回放误差。仅改变 `motor_tau_s` 和一个非负的统一命令延迟，候选网格分别为 `[.002,.005,.010,.020]` 秒与 `[0,.010,.020,.040]` 秒。其余模型参数、2 ms 积分步长、ROS 时间基准、初态拟合方式均沿用现有 `replay_closed_loop`；不在本轮修改质量、惯量、升力系数、阻力或碰撞模型。

固定拟合集：`d03_roll_pitch_seed2026_20261107/replay_input` 和 `d04_yaw_seed2026_20261107/replay_input`；从首个发送 PWM 的 ROS Header 之后 0.30 秒开始，回放 0.50 秒。目标值是两个试验的角速度向量 RMSE 的算术平均，基线为 5 ms 电机时间常数和 0 ms 延迟。预期至少降低该训练目标 10%，且任何单项角速度 RMSE 不比基线恶化超过 20%；这是本轮是否值得进一步验证的**工程筛选规则**，不是用户任务容差或最终 PASS 阈值。报告全部网格及位置、姿态的相应指标，不按结果更改搜索范围、数据或评价时间。

观察到改进也只得到候选参数：ROS 命令 Header 不等于物理生效时刻，初速度由含未来样本的位姿拟合，初始电机信号为猜测，接触及风尚未排除；电机滞后与控制延迟可能相互不可辨识。若无改善或最优值落在边界，保存负结果和原因，不把边界当作实测值。任何模型升级都须另外经不同初态和未用于拟合的检查；封存的 `v2_holdout_axis` 不用于本轮，也不得在误差阈值冻结前解封。此为 V2 允许的最多两轮明确假设模型校准中的第 1 轮。

## 拟合集结果

[网格报告](v2_calibration_round1.json)：平均角速度 RMSE 从 0.02800 降至 0.02092 rad/s，降低 25.28%，达到本轮训练筛选规则；最佳组合为 tau=2 ms、delay=0 ms，两项都处于预设网格边界，因此不可把它们视为测得的真实参数，也没有自动更改默认模型。

## 固定候选的重复进程检查（检查前登记）

使用未参与上面网格拟合的 `v2_roll_pitch_seed314159_20261108` 与 `v2_yaw_seed27182_20261108`，分别转换原始记录并按同一 0.30–0.80 秒窗口比较基线 5 ms/0 ms 和拟合候选 2 ms/0 ms；不搜索新参数。沿用平均角速度 RMSE 至少降低 10% 且每条不恶化超过 20% 的工程筛选规则，并同时记录位置和姿态指标。结果不用于改变候选或阈值；即便通过也仅是同波形不同进程的复查，非独立保留波形或最终验收。

[复查报告](v2_calibration_round1_repeat.json)：候选与基线角速度 RMSE 比值分别为 0.804 和 0.901，两项算术平均降低 19.12%，达到预先声明的工程筛选规则。结论仍限于相同波形、不同进程；2 ms 和零延迟均落在原网格边界，不能认定物理参数，默认模型未更改。还需冻结任务阈值、验证时间同步、碰撞与风等前提后，才能使用独立保留集进行正式评价。
