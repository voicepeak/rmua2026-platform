# G1 参数可辨识性摘要（两轮校准后）

本页只汇总已保存的两轮校准网格，不重新拟合、不读取封存保留集、不修改模型。机器可读结果与源报告哈希见 [v2_identifiability.json](v2_identifiability.json)，生成命令：

```powershell
.\.venv\Scripts\python.exe -m foundation.analyze_v2_identifiability
```

## 模型族与网格

被评估的模型族是“一阶电机滤波 + 一个非负统一命令延迟”。第一轮网格为 `motor_tau_s ∈ {2,5,10,20} ms`、`delay ∈ {0,10,20,40} ms`；第二轮为 `motor_tau_s ∈ {0.5,1,2,5} ms`、`delay ∈ {0,2,5,10} ms`。两轮都只改变这两个参数，其他物理、初态、时钟和评价窗口不变。

## 结果

| 轮次 | 最优 `tau` | 最优 `delay` | 目标 | 相对基线 | 网格边界 |
|---|---:|---:|---:|---:|---|
| 第一轮 | 2 ms | 0 ms | 平均角速度 RMSE 0.02092 rad/s | -25.28% | 是 |
| 第二轮 | 0.5 ms | 0 ms | 归一化目标 0.91952 | -8.05% | 是 |

第二轮中，最优 `tau=0.5 ms` 与 `tau=1 ms` 都在 `delay=0`；`tau=2 ms` 是基线，`tau=5 ms` 更差。相对最优目标 5% 以内的候选只有：

- `tau=0.5 ms, delay=0`；
- `tau=1.0 ms, delay=0`。

`delay=0` 是下边界，任何正延迟都使目标变差：在 `tau=0.5 ms` 时，2/5/10 ms 延迟分别使目标变为 1.030/1.221/1.573（相对最优约 +12%/+33%/+71%）。第一轮的延迟惩罚更大，10 ms 延迟已使目标从 0.02092 升至 0.04714 rad/s。这个形状说明在当前“ROS Header 作为命令零时刻”的模型里，延迟参数被推向下边界；它不能证明物理执行延迟为零，因为时钟基准误差、初态估计和模型结构误差都可能被同一个参数吸收。

最优候选也没有在所有拟合记录上一致改善：第二轮四条记录的角速度 RMSE 比值为 0.814、1.007、0.885、0.971；其中一条基本不变。位置/姿态 RMSE 的变化同样很小：

| 指标（第二轮） | 最优候选范围 | 基线范围 |
|---|---:|---:|
| 位置 RMSE | 6.50–7.15 mm | 6.56–7.25 mm |
| 姿态 RMSE | 0.048–0.499° | 0.048–0.570° |
| 角速度 RMSE | 0.00392–0.04026 rad/s | 0.00390–0.04546 rad/s |

这些是同一批拟合记录上的事后指标，不是独立保留集误差，也不是官方容差。

## 可辨识性结论

1. 在当前模型族和网格内，只能给出“`tau` 不高于约 1 ms、延迟在 ROS Header 基准下接近零”的候选区间；`tau` 最优在下边界，无法区分 0.5 ms 与更短时间常数。不能把 0.5 ms 当成实测电机参数。
2. 延迟与时间基准、初速度估计、接触/风未排除项相互混淆。正延迟被稳定拒绝，更可能说明当前 Header 基准已经偏晚或模型结构不适配，而不是物理延迟为零。
3. 第一轮的最优值在 `tau`/`delay` 两个边界，第二轮最优仍在两个边界；按 V2 规则停止继续扩大参数网格。
4. 参数辨识子问题保持 **BLOCKED**。恢复条件不是更多网格，而是新的独立测量能力：可校验的物理时钟、低扰动指令接收/电机状态记录、独立初速度或接触证据。

本页不改变 G1 的 PARTIAL 状态，也不把任何候选参数写入默认模型。

## 后续官方无断点时钟证据（2026-11-09）

四个 `heldout_mix` 自由落体尾段（其中两个进程被 motion guard 中止，原始记录保留）给出源时间竖直加速度 9.7832–9.7908 m/s²，相对 `g=9.80665` 偏差约 -0.24% 到 -0.16%，二次拟合 RMSE 0.012–0.021 mm；主机到达时间拟合的偏差和残差更大且不稳定。详见 [v2_ballistic_clock_audit.md](v2_ballistic_clock_audit.md) 和 [官方运行记录](v2_official_run_20261109.md)。

这支持“姿态源时间在这几个短自由落体窗口内是均匀物理时间”，但没有给出指令实际生效时刻、电机状态或独立初速度；因此它收窄了时钟假设，不解除 G1 参数辨识 BLOCKED。两个自由落体进程还被运动保护中止，不能当作完整飞行验收。
