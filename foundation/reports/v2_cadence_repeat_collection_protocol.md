# G1 P01/P06：不同命令频率的无断点重复采集

采集前固定：针对已有相同共模波形 `cadence20`、`cadence50`、`cadence100`，分别以 seed 456 和 2026 在新进程采集，与历史 seed 123 合计每频率三次。每次维持原有波形、频率、保护及专用容器清理；逐次启动以避免端口冲突。若运行或数据下载发生不确定错误，先停止本批次并检查远端状态，保留所有记录。

首段共同油门可为 P01 稳定输入提供观测，频率对照为 P06 提供重复性数据；但启动时可能接触地面、时间同步和初始状态未匹配，不能直接将这六次采集视为无碰撞物理验收或盲保留集。物理延迟仍未与消息回显延迟分离；训练误差预算和正式阈值尚未冻结，不据此次采集数直接宣布通过。

固定重复性分析窗口为首个 PWM 发布源时间之后 0.60–1.00 秒，每 10 ms 插值一次，平移和旋转相对窗口起点归一化；报告每频率三次进程的两两位置和姿态差、实际 PWM 阶段切换时刻及初态。此窗口覆盖 0.20 共模阶段的部分区间，不能据此断定无地面接触，也不覆盖完整波形或保留集。分析前检查每个阶段的实际 PWM 数值序列一致、源时间覆盖和采样间隔；不完整结果应显式报错。

结果：六次新增进程均完成且容器停止；结合各自历史 seed 123，[固定窗口比较](v2_cadence_repeatability.json)中同频率三次采集两两最大相对位置差的范围：20 Hz 为 1.28–2.70 mm，50 Hz 为 0.17–0.85 mm，100 Hz 为 1.17–3.82 mm。各频率实测命令间隔中位数分别约 50.19–50.27、20.24–20.26、10.23 ms。各窗口基本是竖直运动、姿态无变化，因此姿态差为零不代表姿态动力学已验证。实际 PWM 切换时间、初态和源文件哈希均在报告内。

这些是同频率样本间差异，而非不同频率的误差上限或正式容差；也不能将消息发布时间差直接作为物理响应延迟。地面接触、初态、控制执行时间、任务误差预算和独立保留集仍需确认，P01/P06 为 PARTIAL。
