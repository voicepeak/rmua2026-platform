# G3 风与力度衰减：分层证据矩阵（2026-11-09）

本页把现有证据按“生成、触发、施力、力场状态”分层，明确哪些是源码/受控事实，哪些是实测响应，哪些仍是 UNVERIFIED。它不改变 G3 的 PARTIAL 状态，也不把近似模型称为官方等价。

## 1. 风生成层

| 项目 | 证据 | 状态 |
|---|---|---|
| 12.0.0.5 风关键帧生成 | 注入阶段 4–6、seed 123/456/2026、各两次重复，18/18 关键帧字节精确匹配 | 受控生成成立 |
| 自然赛程随机流 | 注入前没有普通 libc 随机消费；自然赛程的消费顺序未验证 | UNVERIFIED |
| 空间区域与坐标 | `CandidateWindField` 要求调用方显式给出 `source_to_ned`、NED 边界和时间偏移 | 工程接口成立，官方区域未知 |
| 时间覆盖 | 采样器拒绝超出关键帧区间的查询；float32 重合/末帧回绕被拒绝 | 实现边界成立 |
| 自然风区生成 | 无自然路线连续官方风区证据 | UNVERIFIED |

**可用区间**：只在“注入阶段、已知关键帧、显式坐标变换”的受控回放中可用。自然赛程、自然风区边界和官方随机数消费顺序没有通过证据。

## 3. 力度衰减层

| 项目 | 证据 | 状态 |
|---|---|---|
| 0.25 目标比例 | 强制 flag 1→0→1 时四电机目标/滤波值约为输入的 0.25/1.0；作用点在电机目标、滤波之前 | 受控强制条件成立 |

| 2 秒累计规则 | `OutTimeCounter` 仅在 flag=0 时累计，严格大于阈值触发；返回 flag=1 不清零；suppression 只抑制触发 | 候选分支测试 |
| 自然区域边界 | 道路/港口/工厂盒子与 2 cm 球假设在若干路线/seed 上相关，但同路线重复出现 5/10 不一致；3.8 cm 内缩为事后拟合 | UNVERIFIED |
| W02 穿越边界 | `CandidateWindField` 单元测试覆盖区域内外与时间偏移；自然边界穿越未测 | 候选接口成立 |
| F02 多次进出/2 秒边界 | 只有强制 flag 和候选计数器测试；自然多次进出未测 | UNVERIFIED |

**可用区间**：受控 flag 条件下 0.25/1.0 和累计计时分支可用；自然区域成员、边界延迟、恢复行为和官方失败状态机未验收。2 cm 球/6 cm 偏移和 3.8 cm 内缩是候选假设，不是官方参数。

## 4. 结论

- G3 的生成层和受控施力层有较强实现/样本证据；自然风区、自然施力、W01、F01 和自然 F02 均未通过。
- G3 以 G1 的时钟/接触/初态可辨识性为前提；在 G1 未通过时，G3 只能提供标注为近似/UNVERIFIED 的扰动训练能力。
- 不将 `0.25`、`2 cm`、`6 cm`、`3.8 cm` 或任何风矢量写成官方参数或固定默认值。
- 恢复条件：自然路线连续风/力场观测、可校验物理时钟、独立初态和接触排除；或者明确接受 G3 以 PARTIAL 收口。
