# 四电机差动脉冲方向审计（2026-11-09）

本审计只核对已有三次独立进程的四电机差动脉冲数据，不新增校准网格、不使用 GDB、不读取封存保留集。机器可读结果见 [v2_motor_direction_audit.json](v2_motor_direction_audit.json)，SHA-256 `bcf5a515f6f76a845d591ab3c442ea810987ca3d14762f828b01df4687fffb4f`。

## 数据

使用 `d03_differential_retry_20261107`、`d03_differential_seed456_20261107` 和 2026-11-09 新采集的 `v2_official_differential_seed260007_20261109` 的 `phase_analysis.json`。三次波形相同：共模 0.20 升空，然后依次给电机 0/1/2/3 单独 +0.004 脉冲，最后 0.16 共模和归零。每个脉冲段的角速度斜率来自原始 IMU 的线性拟合，样本数 9–12。

## 结果

| 电机 | 候选 x/y/z 符号 |
|---|---|
| 0 右前 | (-, +, +) |
| 1 左后 | (+, -, +) |
| 2 左前 | (+, +, -) |
| 3 右后 | (-, -, -) |

两次采集的实测 x/y 符号：

| 电机 | retry 20261107 | seed456 20261107 | seed260007 20261109 |
|---|---|---|---|
| 0 | (-, +) | (-, +) | (-, +) |
| 1 | (+, -) | (+, -) | (+, -) |

| 3 | (-, -) | (-, -) | (-, -) |

- 三次进程的 x/y 符号与候选 **12/12 一致**，且三次采集完全相同。
- 四个脉冲段的 yaw（z）斜率绝对值都低于 0.1 rad/s² 报告阈值，因此 **z 符号未解析**；不能宣称四电机 yaw 方向已验证。
- 这支持“电机 0–3 的 roll/pitch 响应符号在该波形和当前机体系解释下正确”，不独立解码运行时通道名称、不证明真实旋向或完整包线。

## 限制

- 公开电机顺序和候选 FRD 机体系是假设，不是运行时解码结果。
- 脉冲斜率包含先前运动、重力耦合和未知作动延迟；地面接触与后续飞行未逐段分类。
- 只有同一差动波形的三个进程，不覆盖不同幅度、频率、温度或完整比赛包线。
- 该证据不建立 PWM 范围、裁剪、保持、超时，也不使 G1 通过。

## 状态

G1 仍为 **PARTIAL**，参数辨识 **BLOCKED**。电机的 roll/pitch 符号一致性可作为 G1 的方向子证据；yaw/z 方向、完整旋向、真实执行时刻和保留集误差仍未完成。
