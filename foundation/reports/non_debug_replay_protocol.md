# 无断点采集的固定窗口动力学回放

在查看这两次无断点采集的回放误差之前，固定使用已采集的 `clock_pair_yaw_seed314159_20261108` 与 `clock_pair_steps_retry_seed27182_20261108`。转换原始 ROS 位姿、IMU 和 PWM 发布记录，以第一条 PWM 发布源时间加 0.30 秒开始，固定持续 0.50 秒；使用现有候选参数、5 ms 电机时间常数、0 ms 假定命令延迟和 2 ms 积分步长。所有指标、输入哈希和原始数据均保留，不依据结果调整窗口或参数。

输入来自采集时发布的 ROS 时间戳：假定其与位姿及 IMU 源时间可比较，但尚未确认实际指令进入物理模型的时间。初始位置和速度使用前后各 0.12 秒位姿拟合，初始电机状态使用当时命令而非实测。风、空气阻力和碰撞未纳入；无碰撞条件尚未证实。因涉及未来位姿、非盲分析和无固定验收阈值，结果仅用于诊断，不能作为 Gate B 验收。

结果：共同油门阶跃的位置 RMSE 6.29 mm、最大值 14.44 mm，姿态 RMSE 0.052°；偏航的位置 RMSE 7.17 mm、最大值 17.05 mm，姿态 RMSE 0.043°。对应的速度 RMSE 0.0364/0.0482 m/s 来自事后位姿拟合，并非独立速度真值；角速度 RMSE 0.00390/0.00413 rad/s。完整数据分别在 [阶跃报告](non_debug_steps_seed27182.json)与 [偏航报告](non_debug_yaw_seed314159.json)。模型不含碰撞和风，故这些结果不能代表整个飞行包线的误差。
